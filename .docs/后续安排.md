### 工作项

#### 1.1 后端 Dockerfile（2 小时）

**文件**: `backend/Dockerfile`

```dockerfile
# 多阶段构建
# Stage 1: Builder
FROM python:3.11-slim as builder

WORKDIR /app

# 安装依赖
COPY backend/requirements.txt .
RUN pip install --user --no-cache-dir -r requirements.txt

# Stage 2: Runtime
FROM python:3.11-slim

WORKDIR /app

# 创建非 root 用户
RUN useradd -m -u 1000 lunaris

# 从 builder 复制依赖
COPY --from=builder /root/.local /home/lunaris/.local
ENV PATH=/home/lunaris/.local/bin:$PATH

# 复制应用代码
COPY backend/ /app/

# 修改权限
RUN chown -R lunaris:lunaris /app

USER lunaris

# 暴露端口
EXPOSE 8000

# 健康检查
HEALTHCHECK --interval=30s --timeout=10s --start-period=40s --retries=3 \
  CMD curl -f http://localhost:8000/health || exit 1

# 启动应用
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

#### 1.2 docker-compose.yml（2 小时）

**文件**: `docker-compose.yml`

```yaml
version: '3.8'

services:
  # PostgreSQL 数据库
  postgres:
    image: postgres:15-alpine
    container_name: lunaris-db
    environment:
      POSTGRES_DB: lunaris_db
      POSTGRES_USER: lunaris
      POSTGRES_PASSWORD: ${DB_PASSWORD:-lunaris_password}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U lunaris"]
      interval: 10s
      timeout: 5s
      retries: 5

  # Redis 缓存
  redis:
    image: redis:7-alpine
    container_name: lunaris-cache
    ports:
      - "6379:6379"
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  # 后端应用
  backend:
    build:
      context: .
      dockerfile: backend/Dockerfile
    container_name: lunaris-backend
    environment:
      DATABASE_URL: postgresql+asyncpg://lunaris:${DB_PASSWORD:-lunaris_password}@postgres:5432/lunaris_db
      REDIS_URL: redis://redis:6379
      JWT_SECRET: ${JWT_SECRET}
      ENCRYPTION_KEY: ${ENCRYPTION_KEY}
      DEEPSEEK_API_KEY: ${DEEPSEEK_API_KEY}
      CORS_ORIGINS: ${CORS_ORIGINS:-http://localhost:5173,http://localhost:3000}
    ports:
      - "8000:8000"
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_healthy
    volumes:
      - ./backend:/app  # 开发模式下挂载源代码
    command: uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 3

  # 前端应用（可选）
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: lunaris-frontend
    ports:
      - "5173:5173"
    environment:
      VITE_API_BASE_URL: http://localhost:8000/api
    depends_on:
      - backend

volumes:
  postgres_data:
    driver: local
```

#### 2.3 GitHub Actions 工作流 - Build & Push（1.5 小时）

**文件**: `.github/workflows/build.yml`

```yaml
name: Build & Push Docker Image

on:
  push:
    branches: [ main ]
    tags: [ 'v*' ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Docker Buildx
      uses: docker/setup-buildx-action@v2
    
    - name: Login to Docker Hub
      if: github.event_name != 'pull_request'
      uses: docker/login-action@v2
      with:
        username: ${{ secrets.DOCKER_USERNAME }}
        password: ${{ secrets.DOCKER_PASSWORD }}
    
    - name: Build and push
      uses: docker/build-push-action@v4
      with:
        context: .
        file: ./backend/Dockerfile
        push: ${{ github.event_name != 'pull_request' }}
        tags: |
          ${{ secrets.DOCKER_USERNAME }}/lunaris-backend:latest
          ${{ secrets.DOCKER_USERNAME }}/lunaris-backend:${{ github.sha }}
        cache-from: type=registry,ref=${{ secrets.DOCKER_USERNAME }}/lunaris-backend:buildcache
        cache-to: type=registry,ref=${{ secrets.DOCKER_USERNAME }}/lunaris-backend:buildcache,mode=max
```

#### 2.4 GitHub Actions 工作流 - Deploy（2 小时）

**文件**: `.github/workflows/deploy.yml`

```yaml
name: Deploy to Production

on:
  push:
    branches: [ main ]
    tags: [ 'v*' ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    if: github.event_name == 'push' && (contains(github.ref, 'refs/tags') || github.ref == 'refs/heads/main')
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Deploy to production
      env:
        DEPLOY_KEY: ${{ secrets.DEPLOY_KEY }}
        DEPLOY_HOST: ${{ secrets.DEPLOY_HOST }}
        DEPLOY_USER: ${{ secrets.DEPLOY_USER }}
      run: |
        mkdir -p ~/.ssh
        echo "$DEPLOY_KEY" > ~/.ssh/deploy_key
        chmod 600 ~/.ssh/deploy_key
        ssh-keyscan -H $DEPLOY_HOST >> ~/.ssh/known_hosts
        
        ssh -i ~/.ssh/deploy_key $DEPLOY_USER@$DEPLOY_HOST << 'EOF'
          cd /app/lunaris
          git pull origin main
          docker-compose down
          docker-compose up -d
          docker-compose exec -T backend alembic upgrade head
        EOF
```

#### 3.1 Prometheus Metrics（2 小时）

**文件**: `backend/config/monitoring.py`

```python
from prometheus_client import Counter, Histogram, Gauge, generate_latest
from fastapi import Response
import time

# 请求指标
request_count = Counter(
    'lunaris_requests_total',
    '总请求数',
    ['method', 'endpoint', 'status']
)

request_duration = Histogram(
    'lunaris_request_duration_seconds',
    '请求耗时',
    ['method', 'endpoint'],
    buckets=(0.1, 0.5, 1.0, 2.5, 5.0, 10.0)
)

# 数据库指标
db_queries = Counter(
    'lunaris_database_queries_total',
    '数据库查询总数',
    ['operation', 'table']
)

db_query_duration = Histogram(
    'lunaris_database_query_duration_seconds',
    '数据库查询耗时',
    ['operation', 'table']
)

# 业务指标
active_users = Gauge(
    'lunaris_active_users',
    '活跃用户数'
)

chat_messages_total = Counter(
    'lunaris_chat_messages_total',
    '聊天消息总数'
)

crisis_events_total = Counter(
    'lunaris_crisis_events_total',
    '危机事件总数',
    ['risk_level']
)

# Prometheus 指标端点
async def metrics_endpoint():
    return Response(
        generate_latest(),
        media_type="text/plain; charset=utf-8; version=0.0.4"
    )

# 中间件
async def monitoring_middleware(request, call_next):
    start_time = time.time()
    
    response = await call_next(request)
    
    duration = time.time() - start_time
    
    request_count.labels(
        method=request.method,
        endpoint=request.url.path,
        status=response.status_code
    ).inc()
    
    request_duration.labels(
        method=request.method,
        endpoint=request.url.path
    ).observe(duration)
    
    return response
```

在 `main.py` 中添加：

```python
from config.monitoring import metrics_endpoint, monitoring_middleware

app.add_middleware(monitoring_middleware)
app.add_route("/metrics", metrics_endpoint)
```

#### 3.3 告警规则（1.5 小时）

**文件**: `prometheus/alerts.yml`

```yaml
groups:
  - name: lunaris_alerts
    rules:
      - alert: HighErrorRate
        expr: rate(lunaris_requests_total{status=~"5.."}[5m]) > 0.05
        for: 5m
        annotations:
          summary: "高错误率告警"
          description: "过去 5 分钟内错误率超过 5%"
      
      - alert: SlowResponse
        expr: histogram_quantile(0.95, lunaris_request_duration_seconds) > 5
        for: 10m
        annotations:
          summary: "响应缓慢告警"
          description: "95% 的请求耗时超过 5 秒"
      
      - alert: DatabaseDown
        expr: up{job="postgres"} == 0
        for: 1m
        annotations:
          summary: "数据库离线"
          description: "PostgreSQL 连接超时"
      
      - alert: HighCrisisEventRate
        expr: rate(lunaris_crisis_events_total[1h]) > 10
        for: 5m
        annotations:
          summary: "高危机事件率"
          description: "过去 1 小时内危机事件超过 10 例"
```

## 💡 实施建议

### 阶段 1：快速启动（第一周）

2. **收益**: 统一开发、测试、生产环境
3. **风险**: 低（不改变功能）

1. **优先级高**: CI/CD 工作流
2. **收益**: 自动化测试、构建、部署
3. **风险**: 中（需要配置 GitHub Secrets）

### 阶段 3：可观测性（第三周）
1. **优先级中**: 监控和告警

## ⚠️ 风险和缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| Docker 镜像构建失败 | 延迟上线 | 提前在开发环境测试 |
