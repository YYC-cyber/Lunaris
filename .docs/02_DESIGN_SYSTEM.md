# 🎨 Lunaris 设计系统文档 (Design)

## 设计理念

Lunaris 的设计哲学是从「工具」转变为「陪伴」。用户打开应用不是在用软件，而是在进入一个温暖的小房间。

### 核心设计价值
- **温暖胜于功能** - 每个像素都传递关怀
- **陪伴感第一** - 交互时刻提醒「有人在听」
- **隐私与安全** - 视觉上营造私密空间
- **现代感** - 毛玻璃、渐变、柔和阴影

## 🎬 动画系统

### 基础动画

```css
/* 消息滑入（0.3s） */
@keyframes slideInUp {
  from { opacity: 0; transform: translateY(12px); }
  to { opacity: 1; transform: translateY(0); }
}
animation: slideInUp 0.3s ease-out;

/* 淡入淡出 */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

/* Typing 气泡（三点跳动） */
@keyframes typingDot {
  0%, 60%, 100% { opacity: 0.4; transform: translateY(0); }
  30% { opacity: 1; transform: translateY(-8px); }
}

/* 脉冲（录音按钮） */
@keyframes pulse {
  0% { box-shadow: 0 0 0 0 rgba(212, 165, 212, 0.7); }
  70% { box-shadow: 0 0 0 8px rgba(212, 165, 212, 0); }
}
```

### 动画应用表

| 元素 | 动画 | 时间 | 触发条件 |
|------|------|------|---------|
| 消息出现 | slideInUp | 0.3s | 消息加载 |
| 背景过渡 | fade | 2s ease | 时间段变化 |
| Typing气泡 | 三点跳 | 1.4s 循环 | AI正在输入 |
| 录音按钮 | pulse | 2s 循环 | 录音中 |
| 按钮悬停 | scale(1.05) | 0.2s | 鼠标悬停 |

### Typing 气泡
```
背景: AI 气泡渐变

### 输入框
```
形状: 圆形 (24px)
背景: rgba(255, 255, 255, 0.6)
边框: 1px solid rgba(212, 165, 212, 0.2)
悬停: rgba(255, 255, 255, 0.8), rgba(212, 165, 212, 0.4)

```

### 发送按钮
```
形状: 圆形 (24px)
背景: linear-gradient(135deg, #D4A5D4 0%, #9B7BA9 100%)
文字: 白色 600 weight
悬停: 阴影提升 + 向上移动 2px

```

### 亲密度进度条
```
容器: 100% 宽, 4px 高

填充: linear-gradient(90deg, #D4A5D4 0%, #9B7BA9 100%)
圆角: 2px

```

### 角色卡片
```
头部: 头像 + 名字 + 当日心语
心语: 10px, 斜体, 紫粉色, 80% 不透明
预览: 最近消息前 20 字, 浅灰色
进度条: 亲密度可视化
选中状态: 半透明紫粉背景 + 内部阴影
```

### 侧边栏
```

边框: 1px solid rgba(212, 165, 212, 0.15)

## 🌈 状态设计

### 常态
- 消息: 渐变气泡 + 阴影
- 输入框: 浅色背景 + 灰色边框

### 悬停
- 按钮: 阴影提升 + 颜色加深
- 卡片: 微妙背景变化 + 圆角背景
- 消息: 无变化（保持稳定）

### 焦点
- 输入框: 紫粉色边框 + 背景变浅
- 按钮: 保持悬停状态

### 禁用
- 按钮: 60% 不透明 + 光标不可点击
- 输入: 背景灰化 + 文字灰化

### 加载态
- Typing 气泡: 三点跳动
- 按钮: 转圈加载图标
- 消息: skeleton 加载条

### 错误态
- 消息边框: 1px solid rgba(232, 93, 117, 0.3)
- 文字: #E85D75 (浅红)

## 📱 响应式设计

### 断点
- **移动设备** < 480px
- **平板** 480px - 768px
- **桌面** > 768px

### 适配规则
- 侧边栏: 桌面显示，移动隐藏（改为底部标签）
- 消息气泡: 最大宽度 60%（桌面）→ 80%（移动）
- 输入框: 完整宽度，减少左右边距
- 头像: 40px → 36px

## 🎯 使用场景案例

### 场景 1: 用户发送消息
1. 用户在输入框输入
2. 按发送按钮 (hover: 阴影+上移)
3. 消息气泡以 slideInUp 动画出现
4. 消息进度条显示
5. 背景逐渐过渡

### 场景 2: AI 正在回复
1. Typing 气泡出现
2. 三点跳动，表示 AI 在思考
3. 用户感受到「被陪伴」

### 场景 3: 深夜聊天
1. 背景自动过渡到深夜紫粉
2. 柔和的色调营造私密感
3. 阴影变软，不刺激视觉

### 场景 4: 提升亲密度
1. 亲密度进度条逐渐填满
2. 颜色从浅紫 → 深紫
3. 到达里程碑时闪烁彩蛋

## 🎭 可访问性 (A11y)

### 色彩对比
- 文字 vs 背景: WCAG AA 标准 (4.5:1+)
- 紫粉 (#D4A5D4) vs 白 = 6.2:1 ✅
- 深紫 (#3D2D4D) vs 白 = 9.5:1 ✅

### 交互最小尺寸
- 按钮: 最小 44x44px
- 可点击区域: 最小 44x44px
- 触摸按钮: 最小 48x48px

### 动画
- 所有动画可通过 prefers-reduced-motion 禁用
- 避免频闪（3Hz 以上）
