# 🎯 Lunaris 原型设计文档 (Prototype & User Flows)

## 核心用户旅程

### 路径 1: 新用户首次体验 (Day 0 - 5 分钟)

```
下载 → 注册 → 验证邮箱 → 选择首个伴侣 → 初体验对话
```

#### 1.1 登录/注册页面

**布局**：中心卡片（400x600px）
- 顶部标志 (Lunaris logo + 文字)
- 双 tab：「登录」| 「注册」
- 登录 tab：
  - 邮箱/用户名输入
  - 密码输入（隐藏/显示toggle）
  - 「登录」按钮 (primary gradient)
  - 「忘记密码」链接
  - 社交登录行（Google/微信，v2.0 特性）
- 注册 tab：
  - 昵称输入
  - 邮箱输入（实时校验）
  - 密码输入 + 确认
  - 密码强度指示（弱/中/强）
  - 协议勾选框
  - 「注册」按钮
- 验证邮箱模态：邮箱+验证码输入，支持重新发送倒计时

**交互细节**
- 失焦时实时校验邮箱格式 / 用户名唯一性
- 密码 8+ 字符，需大小写+数字
- 注册成功后自动进入邮箱验证弹窗
- 邮箱验证成功后弹窗消失，进入首次伴侣选择流程

---

#### 1.2 首次伴侣选择页面

**布局**：6 个角色卡片 × 2 行（卡片 180x240px）

**单个卡片组成**：
- 头部：头像（64x64px，圆角 12px）
- 角色名（16px bold，紫粉色）
- 标签：人设标签 x 2-3（11px，浅灰背景圆形）
- 简介：单行文案（12px，灰色）
- 按钮区：「认识一下」按钮（primary）

**交互**
- 点击卡片整个区域 OR 按钮 → 预览模态
- 预览模态（modal 640x400px）：
  - 左侧：大头像 + 名字 + 性别 + 标签
  - 右侧：详细介绍（2-3 段文字）+ 「选择她」按钮
  - 背景：毛玻璃 + 半透明黑色遮罩
- 选择后弹窗消失，直接进入聊天页面（与该角色已建立关系）

---

#### 1.3 首次对话体验

**进入页面**
- 侧边栏显示该角色卡片（高亮选中状态）
- 聊天区空状态显示「开始聊天吧」
- 输入框聚焦（光标闪烁）

**首次交互**
- 用户输入任意内容 → 发送
- 消息气泡以 slideInUp 动画出现（0.3s）
- AI 正在输入：Typing 气泡出现（三点跳动）
- AI 回复消息出现，可能包含：
  - 纯文字
  - 文字 + 语音（若条件满足，见语音触发规则）
  - 表情包（用户点击表情按钮才发出）
- 聊天记录保存到侧边栏该角色卡片下（最近消息预览）

### 路径 2: 日常聊天 (Day 1+)

```
打开应用 → 选择伴侣 → 聊天 → 涵盖文字/语音/表情/朋友圈
```

#### 2.1 主窗口布局

**左侧侧边栏** (64px 宽，深紫背景)
- 顶部：用户头像 (40x40px，可点击进入「我」页面)
- 标签栏：
  - 💬 聊天 (默认选中)
  - 👥 通讯录
  - 🧭 发现 (朋友圈)
  - 👤 我
- 背景：深紫色 (#3D2D4D)，与聊天区主背景形成对比

**聊天区** (flex: 1)

**顶部 header** (40px 高)
- 左侧：角色头像 (34x34px) + 名字 (bold 15px)
- 右侧：「清空记录」按钮 (text type, 红色)
- 背景：毛玻璃 + 紫粉色边框

**消息区** (flex: 1, overflow-y)

**单条消息气泡**
- 用户消息 (右对齐)：浅蓝背景 (#E8F4F8)，右圆角 16px
- AI 消息 (左对齐)：紫粉渐变，左圆角 16px
- 内边距：10px 14px
- 可能包含：
  - 纯文本（支持换行、emoji）
  - 表情包（单个 emoji 或 CDN 图片）
  - 语音播放器（若是语音消息）
- 消息下方时间戳（可选，满足 5 分钟间隔规则时才显示，12px 灰色）
- 用户消息右键菜单：「撤回」选项（删除该消息，气泡显示「消息已撤回」）

**Typing 气泡** (AI 正在输入时)
- 三个 6px 圆点，紫粉渐变背景
- 每个点依次跳动（延迟 0.2s）
- 1.4s 循环一次

**输入区** (固定底部，60px 高)

| 组件 | 样式 |
|------|------|
| 文字输入框 | 24px 圆角，rgba(255,255,255,0.6) 半透明背景，毛玻璃，边框 1px 紫粉色 0.2 不透明 |
| 按钮区（从左到右） | 1. 表情 emoji，2. 语音录制，3. 发送 (primary gradient) |
| 表情选择器 | 竖向滚动列表，40x40px 单个表情，hover 放大 1.1x |
| 语音录制 | 按下开始录音，松开停止，显示「00:12」秒数计时，录音中脉冲动画 |
| 发送按钮 | 圆形 24x24px，gradient 背景，white icon，hover 上移 2px+阴影加深 |

#### 2.2 消息类型交互流程

**文字消息**
1. 输入框输入 → 按 Enter 或点发送
2. 消息即时显示在右侧（发送前就显示，optimistic update）
3. 后端异步处理，返回 message_id 和 created_at
4. 同时 WebSocket 广播 AI 正在输入事件 → 显示 Typing 气泡
5. AI 回复流式返回 → 消息气泡逐字显示（不是一次性全部出现，而是字-字-字）
6. 流式结束 → 消息固化，隐藏 Typing 气泡

**语音消息（用户发）**
1. 点击麦克风按钮 → 申请录音权限（浏览器弹窗）
2. 授权后页面显示「正在录音」+ 红点脉冲 + 计时器
3. 说话 → 释放鼠标/点击停止 → 显示「预览」弹窗
4. 弹窗内容：
   - 播放按钮 + 音频时长（「0:23」）
   - 识别文本：「你好，今天天气怎么样」（灰色只读）
   - 两个按钮：「重新录制」 vs 「发送」
5. 点「发送」→ 上传音频文件，同时发送识别文本作为消息内容
6. AI 接收到用户语音转文字内容 → 回复文字（可能触发语音回复条件）

**表情包消息**
1. 点击表情按钮 → 弹出表情选择器（modal）
2. 表情选择器中列出所有可用表情（emoji 或 URL 图片）
3. 点击某个表情 → 即时发送（不需要再点发送键）
4. 消息气泡渲染为表情（单个大表情，或 emoji 文本）
5. 后端记录 message.msg_type = 'sticker' 和 sticker_id

**语音消息（AI 发）**
- 触发条件：包含特定情感关键词（爱/想你/喜欢/伤心等）或故事内容标记 + 消息长度 > 20 字
- AI 消息右下角出现小喇叭图标（🔊）
- 点击喇叭 → 播放器展开，显示进度条 + 当前秒数/总秒数
- 自动/手动关闭播放器

#### 2.3 亲密度成长可视化

**侧边栏角色卡片**
- 名字下方：「当日心语」（10px 斜体，紫粉色，80% 不透明）
  - 示例：「今天也要开心呀！」 / 「想你呢~」
- 下方：「最近消息预览」（11px 灰色，最多 20 字 + 省略号）
- 最下方：亲密度进度条
  - 4px 高，100% 宽
  - 背景：rgba(212, 165, 212, 0.1)
  - 填充：linear-gradient(90deg, #D4A5D4 0%, #9B7BA9 100%)，从左往右，宽度 = 亲密度 / 100

**亲密度增长规则**
| 事件 | 增加值 | 上限 |
|------|--------|------|
| 发送一条文字消息 | +1 | — |
| 发送语音消息 | +2 | — |
| 接收语音回复 | +3 | — |
| 点赞 AI 朋友圈 | +5 | — |
| 送礼物 | +10 | — |
| 每日签到 | +5 | 每日一次 |
| 亲密度 | — | 0-100 |

**亲密度里程碑** (达到时弹窗提示)
- 10: 「刚认识」
- 30: 「熟悉起来了」
- 50: 「心有灵犀」
- 70: 「亲密无间」
- 100: 「灵魂伴侣」✨ (解锁专属彩蛋对话)

### 路径 3: 朋友圈 (Moments) 交互

```
侧边栏点「🧭 发现」→ 时间线 → 6 个角色的动态 + 互动
```

#### 3.1 朋友圈时间线

**布局**：中心单栏（最大 600px 宽），上下滚动

**单条动态卡片**（与微信朋友圈类似）
```
┌─────────────────────────────┐
│ [头像] 角色名 · 2 小时前      │  （header 行）
│ 今天早上看了一场很美的日出... │  （正文，可换行，最多 5 行）
│ [图片网格] [图片网格]        │  （图片区，支持 1-9 张，自适应网格）
│ ❤ 12 💬 3                   │  （点赞/评论数，可点击）
└─────────────────────────────┘
```

**动态内容来源**
- 每个 AI 角色每天定期生成 1-2 条新动态（时间由后端随机决定）
- 内容基于角色人设生成（例如医生分享医学知识，设计师分享配色灵感）
- 可包含文字、emoji 或占位图片 URL

**互动方式**
1. **点赞**：点击 ❤ → 填充为红色（可重复点赞/取消）
2. **评论**：点击 💬 → 评论弹窗打开
   - 展示已有评论列表（最多显示 5 条，可"查看更多"）
   - 评论输入框（可发送表情 emoji）
   - 支持回复某条评论（@某人）
3. **分享**：长按卡片 or 右上角菜单 → 分享到系统剪贴板
4. **收藏**：长按 → 「收藏」选项 → 该动态加入用户的「我的收藏」

#### 4.2 真人聊天流程

1. 通讯录中点击某个好友 → 切换聊天对象
2. 聊天页面 header 显示该好友名字
3. 聊天区加载与该好友的对话历史
4. 支持发送文字、表情、语音（相同的 UI 组件）
5. 好友的消息和 AI 的颜色/位置相同（都在左侧）
6. 用户消息在右侧（与 AI 对话相同）

**核心差异**
- 与好友的对话不影响与 AI 角色的亲密度
- 好友对话可被双方删除（无法撤回）
- 好友可被移出聊天列表

#### 5.2 知识库操作流程

**上传文档**
1. 点「＋上传文档」→ 文件选择器打开
2. 选择 PDF/Word/TXT 文件
3. 上传进度条显示（0-100%）
4. 上传完成后列表中出现新条目，状态为「处理中...」
5. 后端解析、切块、生成 embedding（约 5-30 秒取决于文件大小）
6. 完成后状态变为「已解析」✅

**文档删除**
1. 点某条文档的「删除」按钮
2. 确认弹窗：「确定删除此文档？删除后无法恢复」
3. 确认后文档从列表消失，向量数据库中的相关 chunks 也被清除

**基于文档提问**
1. 在「基于我的文档提问」框输入问题
   - 例如：「我应该如何开始学习 Python？」
2. 点「问」按钮 or 按 Enter
3. 加载中...显示转圈图标
4. 收到回答后在下方显示卡片：
   - 问题（重复显示用户输入）
   - 回答（基于文档内容的 LLM 生成结果）
   - 可多次提问，历史记录向下堆叠

**关键词检索**
1. 在「关键词检索」框输入关键词
   - 例如：「Python」
2. 点「检索」按钮
3. 显示匹配结果卡片列表：
   ```
   ┌─────────────────────────────┐
   │ 📄 《Python 学习指南.pdf》    │
   │ Python 是一门编程语言，具有... │
   └─────────────────────────────┘
   ```
4. 每张卡片显示文档名 + 匹配的文本片段（50-100 字）

## 交互细节规范

### 按钮状态

| 状态 | 样式 |
|------|------|
| 常态 | gradient 背景，白色文字，阴影 soft |
| 悬停 | 同常态 + 阴影 medium + 向上移动 2px |
| 按下 | 阴影收回到原位，向下移动 1px（压低感） |
| 禁用 | 60% 不透明，光标 not-allowed |
| 加载中 | 显示转圈图标，文字隐藏 |

### 输入框状态

| 状态 | 样式 |
|------|------|
| 空闲 | rgba(255,255,255,0.6) 背景，1px 灰色边框 |
| 悬停 | rgba(255,255,255,0.8) 背景，1px 紫粉色边框 0.4 不透明 |
| 焦点 | 渐变背景，1px 紫粉色边框 1.0 不透明，光标闪烁 |
| 禁用 | rgba(200,200,200,0.3) 灰化背景，光标不可点击 |

### 模态对话框

- 背景：半透明黑色 (rgba(0, 0, 0, 0.4))
- 卡片：毛玻璃 + 紫粉色边框 0.1 不透明
- 动画：淡入 0.2s ease
- 关闭：点外部区域 OR 右上角 X 按钮

### 加载状态

- 小加载：转圈图标 (1.5s 旋转循环)，灰色
- 大加载：屏幕中央骨架屏（消息列表的占位符）
- 提示信息：Toast 通知，3 秒后自动消失

## 响应式适配（mobile / tablet / desktop）

### 桌面 (> 768px)
- 侧边栏宽度：260px
- 聊天区双栏布局：侧边栏 + 朋友列表 + 聊天主体
- 模态宽度：400-640px

### 平板 (480px - 768px)
- 侧边栏隐藏或改为底部标签栏
- 全屏单栏布局
- 模态宽度：80% 屏幕宽度

### 移动 (< 480px)
- 侧边栏转为底部标签栏（4 个图标）
- 聊天列表全屏，可滑动
- 消息气泡宽度：80% 屏幕宽
- 输入框贴屏幕底部（iOS 软键盘适配）
- 模态全屏或从底部弹起

## 核心流程状态机

### 聊天发送状态流转

```
未发送
  ↓ [用户点发送]
发送中 (loading)
  ├─→ [成功] → 已发送 (✅显示)
  ├─→ [失败] → 待重试 (❌显示，可点击重新发送)
  └─→ [超时 30s] → 待重试
```

### WebSocket 连接状态

```
已断开 (显示重连按钮)
  ↓ [自动/手动连接]
连接中 (loading spinner)
  ├─→ [成功] → 已连接 (✅)
  └─→ [失败] → 已断开 (❌，3s 后自动重试)
```

### 消息同步状态

```
本地待发
  ↓ [网络可用]
已发送到后端
  ↓ [消息入库]
已同步到所有客户端
```

## 原型验证清单

在开发阶段，逐项验证以下交互点：

- [ ] 新用户从登录到首次对话的完整路径是否通畅（无卡顿/错误）
- [ ] 消息发送/接收是否有网络延迟下的视觉反馈（loading 状态）
- [ ] Typing 气泡是否在每条 AI 消息前显示
- [ ] 语音录制是否能成功识别为文字并发送
- [ ] AI 语音回复是否触发条件明确（无误触发或漏触发）
- [ ] 亲密度进度条是否随对话数增加而上升（UI 数字是否真实）
- [ ] 朋友圈时间线是否能无限滚动加载
- [ ] 知识库文档上传、解析状态转换是否准确
- [ ] 好友添加/拒绝流程是否正常
- [ ] 时间背景是否按设定时间段自动切换
- [ ] 消息撤回后是否显示「消息已撤回」
- [ ] 表情包发送/显示是否正常
- [ ] 侧边栏角色卡片的「当日心语」是否每日更新
- [ ] 右键菜单是否只在用户消息上出现
